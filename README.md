# CarDealPro

Advanced **Car Dealer Management System** built with **.NET Core, Blazor & React**.  
Manage dealers, sales, purchases, customers, suppliers, inventory, and more with a professional dashboard.

---

## Features

- **🏠 Dashboard** – Overview of sales, purchases, inventory, and KPIs.  
- **💰 Sales** – Manage vehicle sales, invoices, payment tracking, and sales history.  
- **📦 Purchase** – Add new vehicles, supplier orders, and purchase history.  
- **👤 Customers** – Customer database, contact info, and purchase history.  
- **🏪 Dealers** – Manage partner dealerships and their inventory.  
- **🚚 Suppliers** – Supplier list, orders, and deliveries.  
- **📊 Inventory** – Track available vehicles, status, and location.  
- **💳 Finance / Payments** – Installments, receipts, pending payments, and reports.  
- **📈 Reports** – Sales, purchase, inventory, and revenue analytics.  
- **⚙️ Settings / Admin** – User roles, permissions, and system configurations.  

---

## Tech Stack

- **Backend:** .NET Core, Entity Framework Core ,asp.net
- **Frontend:** Blazor, React, Bootstrap  
- **Database:** SQL Server  
- **Tools:** Azure, Docker  
- **Authentication:** JWT + Role-based access
